# python-data-analysis-projects
Python data analysis projects: solar adoption across Australian states and territories (standardised by population, with trends over time), and a FIFA World Cup 2026 analytics report.
This repository holds two Python data analysis projects.

1. Solar Adoption Analysis by State and Territory: combines solar capacity, ABS population and postcode data to compare solar adoption across Australian states and territories, standardised by population, and looks at how adoption changed over time.

2. FIFA World Cup 2026 Analytics: an analysis of the tournament using football data.
